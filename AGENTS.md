- Cron-aangeroepen edge functions valideren hun secret met isCronAuthorized() (edge-secret óf Vault CRON_SECRET via cron_secret_matches), zodat een afwijkende Vault-waarde de planner niet stil laat falen.
- Mailacties (gelezen, ster, map) lopen via edge function mail-action, die eerst de echte mailbox bijwerkt en daarna de database; de sync neemt gelezen/ster uit de mailbox over maar wijzigt folder nooit, zodat gearchiveerde/verwijderde mails niet terugkomen.
- Mail sync uses partial UPDATEs for existing messages, excludes Servio-owned labels and folders, and reads Outlook stars from Graph flags; this preserves user edits without insert defaults resetting omitted fields.
- New blocked-sender imports are hidden in Spam and moved through shared mailbox-actions with a persisted pending flag; existing mail folders remain untouched to preserve user actions and retry failed moves.
- Unsubscribe endpoints accept owned email IDs rather than client URLs; RFC 8058 POSTs pin validated public DNS addresses and forbid redirects to prevent SSRF.
- Legacy unscoped sender lists require account-owner confirmation before one-time import because their original owner cannot be inferred safely.
- All mail compose modes use the shared composer and persist draft state in emails.draft_data with folder=drafts under existing user RLS; this makes drafts visible in folder counts and resumable without separate storage.
- Mail sending claims an owned draft before delivery, preserves RFC threading, and converts that row to Sent after provider acceptance; post-delivery copy failures must never trigger another delivery, preventing duplicate sends.
- Scheduled delivery uses the shared sender, atomically claims the queued version, and wakes on enqueue with minute retries only while queued mails exist; cancellation wins before a delivery claim and uncertain delivery is never automatically retried.
- Mail reminders use database-timed transitions and owner/connection-scoped reply matching; inbox_returned_at orders returned mail without changing the original message date, and deadlines begin at accepted delivery using persisted draft choices.
- Inbox selection and shortcut navigation share the displayed filtered mail order; bulk actions reuse individual mailbox operations and retain failed selections for retry. Shortcut preferences are browser-local and user-scoped to prevent account leakage without changing server permissions.
- Mail searches parse operators into structured RPC filters; search_mail is security-invoker, owner-scoped and paginated. Never re-filter full-text matches as literal query strings in the mail list.
- Saved mail views persist under owner RLS; recent searches are browser-local and account-scoped. Conversations load across folders by owner, connection and exact thread ID, never by subject alone.
- Mail notifications run in the authenticated shell and use account-scoped deduplication; permissions are requested only from a user command.
- Vacation replies are sync-driven for IMAP and Outlook, atomically claimed per owner/sender before delivery and never retried after an uncertain send; audit rows exist before sending and remain after success or uncertainty to avoid duplicate delivery.
- Mail settings are grouped in a focused mail section; mailbox signatures and the default connection are owner-scoped and applied by the shared composer.
- Explicit mail document imports use a service-written, owner-readable unique attachment ledger before fetching provider bytes; retries reuse the document ID, existing OCR fills review records, and source links never change accounting rules.
- Mail customer suggestions are user-triggered server-side signature extraction; sender matching is exact case-insensitive and owner-scoped, and suggested values require form confirmation before customer creation.
